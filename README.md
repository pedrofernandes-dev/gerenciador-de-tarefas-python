# Gerenciador de Tarefas

Projeto desenvolvido para praticar Python durante meus estudos em Análise e Desenvolvimento de Sistemas.

## Objetivo

Este programa permite criar e gerenciar uma lista de tarefas diretamente pelo terminal.

## ## Objetivo de Aprendizagem

Este projeto tem como objetivo praticar os conceitos fundamentais da linguagem Python por meio do desenvolvimento incremental de um gerenciador de tarefas.

## Funcionalidades
Atualmente o programa permite: 

- Adicionar tarefas
- Listar as tarefas
